# Office Hardware Specifications

**Total Cost:** 2,479,690 KZT  
**Remaining Budget:** 520,310 KZT (out of 3,000,000 KZT, saved for mice, keyboards, and price changes).

---

### Build 1 — Accountant
* **Load:** 1C accounting software, large Excel tables, banking apps, and PDF documents.
* **Bottleneck:** Single-core CPU speed and SSD reliability. Accounting programs do not use many cores at once, but they constantly read and write database files.
* **Trade-off:** Bought a 4-core Intel Core i3-14100 with built-in graphics instead of a more expensive CPU or video card, and spent the saved money on a reliable Samsung 980 1 TB SSD and a comfortable 24" Dell monitor.
* **Total:** 357,930 KZT (`budget.csv`, rows 2–8)

---

### Build 2 — Sales Manager
* **Load:** Web CRM in Chrome, 35–40 browser tabs, Excel price lists, messengers, and 3–4 hours of Zoom/Meet video calls every day.
* **Bottleneck:** Memory (RAM), not CPU. Chrome with 40 tabs plus a video call uses around 12–14 GB of RAM. On 16 GB, the PC starts lagging and swapping to disk during client calls.
* **Trade-off:** Chose a mid-range Intel Core i5-13400 with built-in graphics instead of an i7 or a video card, and spent the saved money on **32 GB of RAM** instead of 16 GB.
* **Total:** 428,930 KZT (`budget.csv`, rows 9–15)

---

### Build 3 — Web Developer
* **Load:** Code editors (VS Code / WebStorm), local Docker containers, test databases, and local servers running at the same time.
* **Bottleneck:** Multi-core CPU speed, RAM capacity, and fast disk speed for building projects and running containers.
* **Trade-off:** Spent more on an 8-core AMD Ryzen 7 7700, **32 GB of fast DDR5 RAM**, a fast Kingston KC3000 SSD, and a larger 27" QHD monitor so code and terminal fit side by side. Saved money by using the CPU's built-in Radeon graphics because 2D web coding does not need a gaming video card.
* **Total:** 649,920 KZT (`budget.csv`, rows 16–23)

---

### Build 4 — Designer
* **Load:** Adobe Photoshop, Illustrator, Premiere Pro, After Effects, and Figma with large, heavy files.
* **Bottleneck:** Graphics card (GPU) speed for rendering effects, large RAM for heavy layers, and accurate monitor colors.
* **Trade-off:** Put the biggest part of the budget into an **NVIDIA RTX 4060 Ti 8GB** video card, **64 GB of RAM**, a fast Intel Core i5-14600K CPU, and a color-accurate **ASUS ProArt** monitor. Accepted an 8 GB video card instead of a 16 GB card and a 1 TB SSD instead of 2 TB to keep all four computers under the 3,000,000 KZT limit.
* **Total:** 1,042,910 KZT (`budget.csv`, rows 24–32)
